# DogClap

Your code failed. The dog noticed.

Whenever a command, task or debug run ends in an error, a dog pops up in the corner of your editor and lets you know, loudly, whose fault it is. Then it leaves.

Just for fun. No judgement. (A little judgement.)

## Settings

Everything is optional. Search for "DogClap" in VS Code Settings to change when the dog shows up, how big it is, or to swap in your own animation and sound.
